# Python ATM Machine

This is a simple ATM machine program made using Python.
It runs in the console and allows the user to do basic ATM actions.

I created this project to practice Python programming, especially functions,
loops, and input validation.

## Features
- PIN login with limited attempts
- Check current balance
- Deposit money
- Withdraw money
- Menu-based system
- Handles invalid inputs

## Tools Used
- Python

## What I Learned
- How to use functions properly
- How to validate user input
- How to use loops and conditions
- How to organize code to make it more readable

## How to Run the Program
1. Make sure Python is installed
2. Open the project folder
3. Run the file using: python atm.py


## Note
This project is for learning purposes only.
It does not represent a real ATM or banking system.
